# 公文写作技能（移动端版）

这是 [official-document-skill](https://github.com/Liuxiangjian-ai/official-document-skill) 的**移动端适配版**：内容重排为单个 `SKILL.md`，正文约 1.07 万字符，低于 Cherry Studio 移动端对技能入口正文的 24000 字符上限，因此可以在手机端直接安装使用。

## 与桌面版的差别

- 保留：文种判断、格式规则、人民日报式表达规律、反 AI 标准、Humanizer 复检、类型模板、评分表、终检清单。
- 变化：英文说明改写为中文、合并重复条目、删去桌面端专属的执行假设；不含脚本，纯提示词。
- 行为一致：先定文种与行文关系，再提事实，再起草，最后过两遍 AI 味检查。

## 安装（Cherry Studio 手机版）

1. 确认 App 版本 ≥ 0.2.1（技能库从该版本开始提供；推荐 0.3.0）。
2. 把这个仓库设为 **Public**。
3. 手机打开 Cherry Studio → 侧边栏 **技能（Skills）** → **发现 / 添加** → 粘贴仓库链接：
   `https://github.com/<你的用户名>/<仓库名>`
   或直接粘贴 `SKILL.md` 的链接。
4. 安装后在「智能体设置 → 技能」里为本技能打开开关，聊天输入框的 `+` 菜单即可引用。

## 桌面端

桌面端仍建议使用原仓库的完整版（内容更全）；本仓库只解决移动端字符数限制。
